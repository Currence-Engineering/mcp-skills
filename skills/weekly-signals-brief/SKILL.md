# Weekly Signals Brief

Start the week knowing what moved, ranked by what matters. Requires the Currence MCP.

## Steps
1. Set the watchlist: the sectors, companies and themes the user named. If none are named and none are saved in memory or earlier in the conversation, ask once, then proceed.
2. Set the window: the last 7 days unless the user says otherwise. State the dates at the top.
3. Scan Currence for each watchlist item:
   - Market events (announcements, milestones, partnerships, failures).
   - Deals (rounds, M&A, project finance).
   - Policies (new, advanced, passed or stalled).
   - New Currence research, compasses or tech profile updates.
4. For niche themes, search market events by keyword as well as by sector, since specialist topics are often tagged under a broader sector.
5. Rank every signal by how much it changes the picture: does it move capital, policy, credibility or competitive position? Discard routine items.
6. Write the top three in full: what happened, why it matters, and what to watch next.
7. Group the rest by watchlist item, one line each.
8. Link every company, deal, project, policy and report to the Currence platform.

## Tips
- If the assistant supports scheduled tasks, offer to run this brief every Monday morning with the same watchlist.
- If a watchlist item had a quiet week, say "no material signals" rather than padding it.
- When the user tracks a policy topic, such as moratoriums, show what changed since the last brief, not the full history.

## Limits
- Only report signals that are in Currence. Do not fill gaps from general knowledge or older training data.
- No power prices, nodal or LMP data.

## Format
A two-minute read. Date range at the top, the top three, then the grouped one-liners. End with one question the user might want to dig into.
